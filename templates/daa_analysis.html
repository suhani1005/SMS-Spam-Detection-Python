1. Linear Search

Linear Search checks records one by one to find SMS messages containing a given keyword.

Search keyword: {{ search_keyword if search_keyword else "No keyword available" }}

Time Complexity: O(n)

Space Complexity: O(k), where k is the number of matching records returned.

2. Merge Sort

Merge Sort divides the SMS records into smaller parts, sorts them recursively, and merges the sorted parts.

Sorting order: Alphabetical (A–Z)

Time Complexity: O(n log n)

Auxiliary Space Complexity: O(n)

Performance Analysis

Execution time is measured using Python's time.perf_counter().

The measured time depends on the number of SMS records, the computer's performance, and the data being processed. Very small datasets may produce extremely small timings.

These measurements represent individual runs, not an average benchmark.
